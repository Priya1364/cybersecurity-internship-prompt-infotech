# Objectives

The primary objectives of this internship were to:

- Understand networking fundamentals
- Analyze network traffic using Wireshark
- Learn Linux and Kali Linux basics
- Perform passive information gathering
- Study common web vulnerabilities
- Practice OWASP Top 10 attacks in a safe lab
- Learn vulnerability assessment techniques
- Understand penetration testing methodology
- Improve problem-solving skills through practical labs
